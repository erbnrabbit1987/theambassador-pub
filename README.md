# The Ambassador — public overview

**The Ambassador** is a festival ticketing platform concept for **low-budget, break-even–driven** events: artist fees tracked against ticket sales, with ambassador-driven reach, phased pricing, and transparent economics for artists and organisers.

> **This repository contains documentation and project summary only.** Application source code is **not** published here.

---

## Core ideas

- **Multi-event** — several festivals or editions in parallel, each with its own phases, lineup, and rules.
- **Ambassador system** — individual and team ambassador models, codes, quotas, guest tickets, and sales visibility.
- **Dynamic pricing** — time-based ticket phases and discount mechanisms.
- **Artist break-even** — progress toward contracted fees; clarity after break-even where the model allows.
- **Admin tooling** — festival setup, ambassador configuration, reporting, and global settings.

---

## Audience

- **Public** — discover events, buy tickets, redeem ambassador or guest offers.
- **Ambassadors** — codes, dashboards, quotas, analytics.
- **Artists** — break-even and sales insight.
- **Organisers** — full festival and pricing control.

---

## Stack (high level)

Next.js frontend · FastAPI backend · PostgreSQL · Redis · Docker — designed for consistent dev and deployment.
